# Critères d'évaluation du code Python

## Lisibilité
- Les noms de variables doivent être explicites et descriptifs
- Éviter les noms de variables à une seule lettre sauf pour les indices de boucles
- Le code doit être indenté correctement et de façon cohérente

## Documentation
- Chaque fonction doit avoir une docstring expliquant son rôle
- La docstring doit mentionner les paramètres et la valeur retournée
- Les parties complexes du code doivent être commentées

## Modularité
- Les fonctions doivent être courtes, idéalement moins de 20 lignes
- Chaque fonction doit avoir un seul rôle précis
- Éviter la duplication de code

## Gestion des erreurs
- Utiliser try/except pour gérer les cas d'erreur
- Ne pas ignorer les exceptions silencieusement
- Valider les entrées de l'utilisateur

## Complexité
- Éviter les boucles imbriquées inutiles
- Préférer les compréhensions de listes aux boucles simples
- Limiter la complexité cyclomatique des fonctions

## Respect de l'énoncé
- Le code doit répondre exactement à ce qui est demandé
- Tous les cas mentionnés dans l'énoncé doivent être traités
- Les noms de fonctions doivent correspondre à ceux demandés
